\# Wireshark Traffic Analysis Report



\## Objective



Capture and analyze common network protocols using Wireshark.



\## Protocols Investigated



\### DNS



Purpose:

Domain Name Resolution



Observation:

DNS queries were observed for websites visited during testing.



\---



\### HTTP



Purpose:

Web Communication



Observation:

HTTP traffic was identified and observed in plaintext.



\---



\### HTTPS



Purpose:

Secure Web Communication



Observation:

TLS encrypted sessions were observed over port 443.



\---



\### ICMP



Purpose:

Network Connectivity Testing



Observation:

ICMP Echo Requests and Replies were generated using ping.



\## Findings



\- DNS queries reveal domain lookups.

\- HTTP traffic can expose plaintext data.

\- HTTPS encrypts communication.

\- ICMP confirms network connectivity.



\## Conclusion



Wireshark provides visibility into network activity and is useful for network monitoring and security investigations.
